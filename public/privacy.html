Kebijakan Privasi

Terakhir diperbarui: 2 November 2026

Halaman ini menjelaskan data apa yang diproses oleh aplikasi penjadwal dan balasan Threads milik pemilik akun (selanjutnya disebut "aplikasi").

Data yang kami proses

  • Token akses Threads, yang disimpan sebagai pengaturan rahasia di server dan tidak pernah ditampilkan di halaman web.
  • Teks dan gambar post atau balasan yang Anda buat dan setujui untuk dikirim.
  • Data postingan publik yang dicari untuk bahan balasan, serta keputusan setuju atau tolak dari Anda.
  • Catatan waktu dan status pengiriman, untuk memantau apakah posting berhasil.

Tujuan penggunaan

Data hanya dipakai untuk menjadwalkan dan mengirim post serta balasan Threads atas persetujuan Anda. Aplikasi tidak mengirim balasan tanpa persetujuan manual.

Pembagian data

Kami tidak menjual atau membagikan data kepada pihak ketiga, kecuali penyedia layanan teknis yang diperlukan untuk menjalankan aplikasi (hosting dan database), dan API Threads milik Meta untuk mengirim balasan.

Penyimpanan dan penghapusan

Data disimpan selama aplikasi masih digunakan. Anda dapat meminta penghapusan data kapan saja dengan mengikuti petunjuk di halaman Penghapusan Data.
